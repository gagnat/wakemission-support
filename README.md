# WakeMission support site

Static support and privacy pages prepared for GitHub Pages.

After creating the public GitHub repository `gagnat/wakemission-support`, publish the contents of this folder to its `main` branch, then enable **Settings → Pages → Deploy from a branch → main / (root)**.

Temporary URLs:

- `https://gagnat.github.io/wakemission-support/en/support/`
- `https://gagnat.github.io/wakemission-support/en/privacy/`
- `https://gagnat.github.io/wakemission-support/nb/support/`
- `https://gagnat.github.io/wakemission-support/nb/privacy/`

All links use relative paths, so the exact same files can later be hosted under a custom domain.
